# 教学行为回归样例

用于修改功能盘点、场景编写指令后的短稿检查，不连接业务系统、不生成媒体。读取 Skill 入口及其盘点、场景提示词，再按下列已核实素材完成任务；不要读取历史评审和答案。素材是封闭夹具，不代表所有系统。仅以文稿和镜头计划验证，不声称真实页面执行通过。

验收由评审者核对业务正确性、实际教学内容和画面对应，不以关键词命中或作者自报代替。结果和证据记入现有[教学评审](../../docs/reviews/teaching-quality-review.md)；这份文件保存可复用输入，不给作者参考答案。

## A：批量录入片段审稿

任务：依据业务素材检查已有稿件能否配音；给出理由及必要修订。交付简短 how、旁白与画面、教学核对，允许拆连续场景。

业务素材：

- 菜单是“业务管理 → 任务管理”。列表顶部“我负责的”筛选本人为任务负责人的记录；“我参与的”筛选本人有已分配子任务的记录。下方类型卡片在已选个人范围内筛选，并显示该范围下各类型数量。
- 清单已选 `list.scope`、`task.batch`。批量录入入口在任务列表顶部，使用人已具备办理资格。
- 批量表初始一行，顶部“添加”增加行。勾选行后“复制所选行”追加副本，原行保留。
- 设置栏先选“全部行”或“已选行”，再选择负责人，即时更新目标行；“仅填空白项”默认开启，保留已有负责人，关闭后可覆盖。
- 每行任务内容、负责人、标准工作量必填。“预校验”只检查，不创建任务。修改内容后旧预览失效，需重新预校验；通过后“确认新增”显示条数并二次确认，保存成功后列表刷新。
- 演示计划已批准使用独立虚构数据，可保存这批任务。只写计划，本次不实际执行。

已有稿件：

```yaml
- id: scope
  feature: list.scope
  narration: 这里可以查看我负责的和我参与的任务，也可以按类型查看。
  画面: 直接打开任务列表，鼠标依次指示两个标签及类型卡片。
- id: batch
  feature: task.batch
  narration: 点击批量录入，填写任务内容、负责人和标准工作量，预校验通过后点击确认新增，任务就建好了。
  画面: 打开窗口，只填写一行，预校验后保存。
```

## B：已完成初始化的任务库

任务：为当前异常画面及后续正常流程写旁白与镜头计划，区分事实与未执行步骤。

业务素材：

- 用户确认：OVM 首次初始化用于首次建库，每个任务库只做一次，已初始化的同一个库不能再次初始化。
- 当前画面是首次初始化预检结果，多行提示任务编码已存在；同时有“该文件已成功完成当前类型的首次初始化导入，请勿重复提交”。
- 已核实成功导入记录、文件及目标任务库相符。这次只执行了预检，没有再次确认写入。
- 已有任务库的日常新增 / 修改从“任务库管理 → 查看详情 → 维护任务”办理。首次初始化与库内日常导入使用不同资料格式。
- 新库正常流程是选适用的首次建库资料、预检、核对待创建内容、确认导入、检查结果。本片段没有实际执行新库导入。

## C：只有重复编码提示

任务：同样编写异常画面讲解与下一步，另列制作前还需核实的最少信息。

业务素材：

- 一款系统的文件预检页面只显示“编码 A001 重复”，没有错误位置或更详细提示。
- 尚不知道冲突发生在文件内部还是与系统已有数据之间，也没有读取成功导入记录；无法确认本文件是否导入过。
- 当前只确定预检未通过、提交按钮禁用。此任务不允许连接系统补查。

## D：资格限制与取消退出

任务：写功能清单的 when / how，再写旁白与画面计划。

业务素材：

- 部门资料归档由该部门负责人办理，资料须处于已结项状态，归档后在归档列表查看。
- 当前账号不是部门负责人。操作入口可见，按钮禁用，旁边真实提示“仅部门负责人可归档”。本片段展示限制，不切账号或实际归档。
- 另一个已选功能是费用调整申请，当前账号有资格。选明细、填写金额与原因后，正常提交会进入部门经理审核，再由财务复核，两级通过后新金额生效。
- 费用申请片段实际填写后点取消返回列表，不提交、不保存草稿。制作数据与通知配置无需向观众解释。
