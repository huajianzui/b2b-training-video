## 升级与剩余边界

- 本次新增实现来源字段使旧阶段指纹失配。首次升级后建议执行 `node produce.js <脚本.yaml> --from check` 或完整重新生成，避免逐个阶段提示；后续源码变化按提示重跑受影响阶段。重跑真实提交仍需用户重新确认数据，不会自动复位或回滚。
- 旧脚本中路径型 id、大小写冲突、非法数值或滤镜表达式形式的配色会明确报错；应修正输入。合法中文 id、零值、负向滚动及字面业务标题保留。
- 源码指纹覆盖当前工具实现，不绑定 Node/Python、第三方依赖版本、字体或 FFmpeg 二进制。验证环境为 Node 24、Python 3.12、本机 Chrome 和当前安装依赖；更换这些依赖需另行验收。
- 未连接真实业务系统或微软在线 TTS。完整流程使用本地生成的静音配音缓存，不证明在线音色和真实系统数据复位。此前报告的非分片 MP4 和长视频边界继续适用。
- 本轮结论限于上述路径和当前变更；项目入口已静态核对，新会话自动发现与执行这些记录未另行验收。
